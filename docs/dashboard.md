# MES 공장 현황 대시보드

MES의 **공장현황** 페이지(`mes/addons/pages/17_공장현황.py`)입니다. 가공 라인, 프레스 · 용접 · 도장 라인, 물류 · 출하 구역을 한 페이지에서 봅니다.
계산은 `mes/addons/src/factory_dash.py`에 있고, 화면과 분리해서 숫자를 시험으로 검증합니다 (`tests/test_mes_logistics.py` 8번 구간).
설치: `python src\mes_adapter.py --install-addons`

## 화면 구성 (위에서 아래로)

| 구간 | 내용 |
|---|---|
| 3D 공장 화면 | `/3d/factory?embed=1` 을 페이지 안에 끼워 넣음 |
| 한눈에 보기 | 양품 생산, 불량(불량률), 출하 수량(건수), 출하 대기, 출하 차단 LOT, 재고 부족 자재 |
| 주의가 필요한 일 | FAIL LOT 출하 차단, 재고 부족, 라인 무응답, AI 이상 감지 경보, 결함 주입 |
| 라인 현황 | 라인별 상태, OEE(가용률, 성능률, 품질률), 처리량, 병목 |
| 생산 | 제품별 양품, 불량 막대, 작업지시 상태별 건수 |
| 자재 재고 | 입고, 소비, 재고, 남은 재고로 만들 수 있는 완제품 수 (부족이면 빨강) |
| 출하 | 최근 출하, 출하 대기 LOT, 검사 FAIL 로 막힌 LOT |
| 품질 | 완제품 LOT 검사 결과(PASS, PARTIAL, FAIL)와 불량 사유 |
| 계산 근거 | 위 숫자의 정의와 식 (면접에서 설명할 때 쓰는 부분) |

## 숫자의 출처

- 생산: 시리얼 상태 (`COMPLETED` 양품, `SCRAPPED` 불량)
- 재고: 입고한 자재 LOT 수량 - 공정 실행이 소비한 수량. "만들 수 있는 완제품" = 재고 / BOM 단위당 소비량. 완제품 20개 분량보다 적으면 부족.
- 출하: 출하 등록 (`shipment`, `shipment_item`). 출하 가능 수량 = 양품 시리얼 수 - 이미 출하한 수량. 검사 FAIL LOT 는 MES가 거절.
- OEE: 가공 라인은 `oee.compute_oee`, 프레스 라인은 `lineoee.compute_line_oee`. **정의가 달라서 더하거나 평균 내지 않고 라인별로 봅니다.**
  물류 구역은 OEE 대신 입고, 파렛트, 출하 건수.
- 라인 상태: 마지막 `machine.state` 이벤트. 90초 넘게 이벤트가 없으면 "무응답", 이벤트가 아예 없으면 "연결 없음"(경보 아님).

## 알려진 한계

- 물류 · 출하 구역은 프레스 라인 제품(브라켓 A, `FG-BRKA`)만 출하합니다. 가공 부품 완제품 LOT 는 출하 대기 표에 넣지 않고 따로 개수만 알려 줍니다.
- 재고 부족 기준(완제품 20개 분량)은 코드의 `low_units` 값입니다.
