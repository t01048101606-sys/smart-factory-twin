# 용어 사전

화면에 보이는 이름은 `src/terms.json` 한 곳에서 정합니다. 3D, 2D 화면의 **용어** 선택칸과 MES 사이드바의 **용어** 선택으로 현장 용어와 장비 원명칭을 전환할 수 있습니다.
코드 안의 태그 ID(예: `SUP_FWD_SOL`), PLC 프로그램, 이벤트 이름은 그대로입니다. 장비 원명칭은 학원 실습 장비(미쓰비시 Q02H PLC, Pro-face HMI)에서 쓰던 이름입니다.

## 장비와 부품

| 현장 용어 | 장비 원명칭 | 설명 |
|---|---|---|
| 부품 공급기 | 매거진 | 적층한 워크를 쌓아 두고 한 개씩 내보내는 곳 |
| 공급 푸셔 | 공급 실린더 | 공급기의 워크를 가공 위치로 미는 실린더 |
| 드릴링 유닛 | 드릴 | 워크에 구멍을 내는 가공 장치 (모터, 헤드, 상하 실린더) |
| 이송 푸셔 | 송출 실린더 | 가공이 끝난 워크를 컨베이어 쪽으로 미는 실린더 |
| 벨트 컨베이어 | 컨베이어 | 워크를 옮기는 벨트 |
| 분류 푸셔 | 배출 실린더 | 재질 판별 결과가 정품이면 수납함으로 밀어내는 실린더 |
| 정품 수납함 | 금속 배출 박스 | 정품이 모이는 상자 |
| 이종품(NG) 수납함 | 비금속 끝 | 이종품(재질 불일치)이 모이는 상자 |
| 스택 라이트 | 신호등 | 설비 상태 표시등 (녹색 가동, 황색 대기·주의, 적색 이상) |
| 워크 | 작업물 | 가공 대상 부품 |

## 재질 분류

| 현장 용어 | 장비 원명칭 | 설명 |
|---|---|---|
| 정품 | 금속 | 인덕티브 근접센서로 재질을 판별해 금속이면 정품 |
| 이종품 | 비금속 | 금속이 아니면 이종품(재질 불일치). MES 검사에서는 이종품 혼입 불량 (사유 MAT_MIX) |
