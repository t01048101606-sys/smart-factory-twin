# 협동로봇 팔레타이징 셀

프레스 · 용접 · 도장 라인 끝에서 협동로봇이 워크를 **비전 검사 → 집기 → 양품은 파렛트에 5개씩 적재, 불량은 NG 수납함**에 넣습니다.
파렛트가 차면 물류 구역으로 넘어가서 AGV와 트럭으로 출하됩니다. 시뮬레이터는 `src/cobot_sim.py`, 3D 장면은 `src/scenes/cobot.json`(`tools/make_cobot_scene.py`)입니다.

```
프레스 라인 끝(piece.exited) -> 인피드 컨베이어 -> 정지 블록 -> 비전 검사(1초) -> 로봇이 집기
   양품: 파렛트 칸 0~4 순서로 적재 -> 5개가 차면 cobot.pallet_closed -> 물류 구역이 파렛트로 받음 -> AGV -> 출하 트럭 -> MES 출하
   불량: NG 수납함
라인이 멈춘 뒤 셀이 다 비면 모자란 파렛트도 마감 (partial)
```

## 로봇팔과 역기구학

4관절(yaw 좌우, shoulder, elbow, wrist 위아래) + 그리퍼입니다. 윗팔 3.2, 아랫팔 3.0, 손목에서 그리퍼 끝까지 1.3(장면 단위)이고, 그리퍼는 항상 아래를 향합니다.
집는 위치, 파렛트 5칸, NG 상자, 각 위치 위 1.3 높이, 홈 위치는 **역기구학**(`ik`)으로 관절 각도를 구하고, 3D 장면은 상태의 `arm` 각도를 그대로 씁니다.
시험에서 15개 지점 모두 닿고, 시뮬레이션 중 집을 때와 놓을 때 그리퍼 끝 위치가 목표와 일치하는 것을 확인합니다 (`tests/test_cobot.py`).
동작 하나(집기 → 놓기)는 약 5.1초라서 라인 사이클(8초)보다 빠르고 작업물이 쌓이지 않습니다.

| 동작 | 시간 |
|---|---|
| 집는 위치 위로 이동 | 1.2초 |
| 내려가기, 그리퍼 닫기, 올라오기 | 0.5, 0.4, 0.5초 |
| 목표 위로 이송 | 1.4초 |
| 내려가기, 그리퍼 열기, 올라오기 | 0.5, 0.4, 0.4초 |
| 비전 검사 (인피드 끝에서) | 1.0초 |

## 이벤트 (`cobot_events.py`, 라인 ID `LINE-COBOT-01`)

| 이벤트 | payload | 설명 |
|---|---|---|
| `vision.inspected` | `result`(good, scrap), `confidence` | 비전 검사 결과와 신뢰도 (0.94~0.994, 표시용) |
| `cobot.placed` | `target`(pallet, ng_bin), `slot`, `cycle_s` | 파렛트 칸 또는 NG 상자에 놓음, 집기 시작부터 걸린 시간 |
| `cobot.pallet_closed` | `pieces`, `partial` | 파렛트가 찼다 (partial = 라인이 멈춰서 모자란 채로 마감) |

MES 어댑터는 이 이벤트를 `machine_event`에 저장만 합니다 (작업지시 같은 MES 기록은 만들지 않고, 가공 라인 처리로 흘러가지 않음).
물류 구역은 `cobot.pallet_closed`로 파렛트를 만듭니다 (`LogisticsEventBridge(from_cobot=True)`). 셀이 없을 때는 예전처럼 라인 끝 양품 5개를 바로 파렛트로 만듭니다.

## 3D 뷰어의 그룹(관절) 구조

로봇팔은 `shape: "group"`(부모-자식) 구조라서 어깨가 돌면 팔 전체가, 팔꿈치가 돌면 아랫팔과 손목이 같이 움직입니다. 형식은 `scene_format.md`의 "그룹과 회전".
(트럭 바퀴, 드릴, 문 같은 다른 디테일에도 같은 방식으로 쓸 수 있습니다.)

## 조작

공장 화면의 협동로봇 카드에서 **파렛트 마감** 버튼으로 모자란 파렛트를 바로 마감할 수 있습니다 (셀이 다 비어 있을 때). `POST /api/cobot/control {"action": "flush"}`.
상태는 `GET /api/cobot/state`.

## 시험

`python tests\test_cobot.py`(역기구학, 집기와 놓기, 파렛트, 이벤트, 물류 연동), `python tests\test_cobot_flow.py`(프레스 라인 → 로봇 → 물류 → MES 출하 전체 흐름),
`python tests\test_factory.py`(3D 뷰어: 관절 회전 = 상태의 각도, 그리퍼 손가락 간격, 부품 위치와 색, 스택 라이트)

## 알려진 한계

- 셀의 위치(`factory.json`의 `offset`)는 임시입니다. 지금은 프레스 라인 끝 옆에 놓았지만 컨베이어와 3D로 이어져 있지는 않습니다 (작업물이 인피드 시작점에 나타납니다).
- 파렛트가 차면 나무 파렛트는 그대로이고 놓인 워크만 사라집니다. 파렛트가 롤러로 나가는 동작은 디테일링 단계에서 만들 예정입니다.
