# 한 장 요약 (면접 · 지원서용)

## 개발 방식 (면접에서 먼저 밝히기)
AI 코딩 도구(Claude)와 함께 만들었습니다. 설계 판단(구조, 이벤트 규격, 실제 설비 기준)과 검증은 제가 하고, 구현은 AI와 반복했습니다. 그래서 "시험으로 검증되는 구조"를 먼저 만들었다고 설명하면 됩니다.

## 한 문장
자동차 부품 공장을 **시뮬레이션하고 3D로 보여 주고 MES와 실시간으로 연결**한 디지털 트윈입니다. 설비 이벤트가 작업지시, LOT, 시리얼, 검사, 출하 기록이 되어 MES에 쌓입니다.

## 30초 설명
"교육과정에서 배운 PLC로 가공 라인을 돌리고, 프레스 · 용접 · 도장, 협동로봇 검사, 물류 출하 구역을 파이썬 시뮬레이터로 만들어 한 공장으로 이었습니다.
모든 설비가 같은 형식의 이벤트를 내보내고, 어댑터가 그 이벤트를 제가 만든 MES에 넣어서 작업지시부터 출하까지 추적됩니다.
3D 화면에서는 프레스 슬라이드, 용접 로봇, 전착조 행거, 트럭 하역까지 실제 설비 사양을 조사해서 반영했고, 좌표와 연결은 시험으로 검증했습니다."

## 숫자로 말할 수 있는 것
| 항목 | 내용 |
|---|---|
| 구역 | 4개 (가공 라인, 프레스 · 용접 · 도장, 협동로봇 셀, 물류 · 출하) |
| 이벤트 | 공통 스키마 22종 → MES 기록 (작업지시, 공정 실행, LOT, 시리얼, 검사, 출하, 설비 이벤트) |
| 병목 | 프레스 4초, 용접 6초, 도장 8초 → 도장이 병목, 처리량 7.5개/분. 용접 결함(2.2배 느려짐) 주입 시 앞 공정이 막히고 재공품이 쌓임 |
| 협동로봇 | 4관절 역기구학, 15개 지점 도달 확인, 동작 1회 약 5.1초 (라인 사이클 8초보다 빠름) |
| 검증 | 시험 파일 22개, 용접 건 충돌 2,001개 자세 검사, 화면 숫자 ↔ MES 데이터 대조 |
| 규모 | 파이썬과 자바스크립트 약 5,000줄 (시뮬레이터, 3D 뷰어, 어댑터, 장면 생성기) |

## 예상 질문과 답
**Q. 왜 MES를 고치지 않고 어댑터로 붙였나요?**
기존 MES의 검증 규칙(공정 순서, LOT당 검사 1회)을 그대로 통과시켜야 데이터가 믿을 만해서입니다. 작업물 N개를 작업지시 1건으로 묶어서 규칙에 맞췄습니다.

**Q. AI는 무엇을 하나요? 설비를 멈추나요?**
사이클 시간이 평소와 다른지 판정하고 경보만 냅니다(MAD 기반 점 판정 + EWMA 추세 판정). 정지는 PLC가 판단합니다. AI의 요청이 PLC 로직에 연결되어 있지 않은 것은 안전을 위한 의도입니다.

**Q. 시뮬레이션이 실제와 얼마나 같나요?**
형상과 수치(프레스 정지시간과 안전거리, 스폿 용접 로봇 사양, 전착조 조건, 트럭 규격)는 자료를 조사해 반영했고 근거를 문서로 남겼습니다. 동작 시간, 센서, 비전 판정은 단순 모델이라 실제와 다릅니다. 한계는 README에 적었습니다.

**Q. 가장 어려웠던 것은?**
(1) OpenPLC 연동: 빌드가 "성공"인데 실행이 안 되었는데, 설치 로그를 열어 Windows 줄바꿈(CRLF)이 원인임을 찾았습니다. 타이머 32비트 오버플로 같은 문제도 신호 변화를 시각과 함께 기록해서 추측이 아니라 관측으로 고쳤습니다 (`docs/openplc.md`).
(2) 3D가 맞는지 확인하는 일: 보기 좋은지는 눈으로 봐야 하지만 좌표와 연결은 계산으로 먼저 검증하고, 화면 캡처로 겹침과 높이 오류를 고쳤습니다. 로봇 어깨 높이가 0.47 어긋난 것도 용접 로봇을 만들며 계산으로 찾았습니다.

**Q. 생산기술 직무와 어떻게 이어지나요?**
라인 밸런싱(병목 공정), 설비종합효율(OEE), 재공품(WIP), 불량 추적(LOT, 시리얼), 안전(라이트 커튼, 정지시간 기준 안전거리)을 직접 모델링하고 숫자로 확인했습니다.

**Q. 다음에 한다면?**
MES에서 작업지시를 내려 트윈을 제어하는 양방향 연동, 재공품 완충 구간과 AGV 이송, 실제 장비 신호 연결(OpenPLC의 `HW_*` 입력), PostgreSQL 전환입니다.

## 시연 순서 (영상 약 90초)
`/3d/factory?demo=1` → 카메라가 전체, 가공, 프레스, 용접, 도장, 협동로봇, 입고, AGV, 출하, 결함 주입, 해제를 차례로 돕니다.
이어서 MES **스마트 팩토리 현황**에서 같은 수치를 확인합니다 (종합 → 프레스 라인 OEE → 물류 · 출하).
