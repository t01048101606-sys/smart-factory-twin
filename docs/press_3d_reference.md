# 프레스 · 용접 · 도장 라인 3D 디테일링 근거

3D 모델의 구조와 동작을 실제 설비 자료에 맞춘 근거입니다 (웹 조사 2026-11-06). 치수는 포트폴리오용 모델 크기이고, 실제 설비의 수치를 그대로 쓴 것이 아닙니다.

## 프레스 (스트레이트 사이드 기계식 프레스)

| 모델 요소 | 근거 |
|---|---|
| 크라운, 4개 컬럼(업라이트), 베드, 볼스터 | 스트레이트 사이드 프레스는 양쪽 수직 컬럼이 이름의 유래이고, 크라운(모터, 플라이휠, 클러치 장착), 컬럼(가이드인 깁 포함), 베드, 볼스터로 구성된다. 볼스터는 베드를 보강하고 금형을 받는다. |
| 타이로드 너트 | 대부분의 스트레이트 사이드 프레스는 프리스트레스를 준 타이로드로 프레임을 압축 상태로 묶는다. |
| 플라이휠(회전), 에어 탱크 | 전동기가 플라이휠을 돌리고 클러치가 맞물리면 크랭크축을 통해 슬라이드가 상하 운동을 한다. 클러치와 브레이크는 공압으로 작동한다. |
| 슬라이드(램) + 상, 하부 금형, 플런저 | 슬라이드는 가이드를 따라 오르내리며, 작업 높이(셧 하이트)는 볼스터 윗면에서 슬라이드 아랫면까지 하사점 기준으로 잰다. |
| 코일 라인: 언코일러, 슬랙 루프, 교정기(7롤), 서보 롤 피더 | 코일 공급 라인은 언코일러(릴), 교정기, 롤 피더로 이루어지고, 슬랙 루프가 연속 풀림과 프레스의 간헐 이송을 이어 준다. 피더 패스 높이는 약 1.2~1.3m(49 in ±5 in 사례). |
| 라이트 커튼, 양손 조작 | OSHA 29 CFR 1910.217: 안전거리 Ds = 63 in/s × 정지 시간(하사점 약 90도 기준). 양손 조작은 작업자마다 하나씩, 손을 떼면 슬라이드가 멈춘다. |

## 용접 셀 (스폿 용접)

| 모델 요소 | 근거 |
|---|---|
| 6축 스폿 용접 로봇(4관절로 단순화) | Yaskawa Motoman SP 시리즈: 가반 80~210kg, 수평 리치 2.2~3.1m. 모델의 팔 길이는 2.7 + 2.5 + 건. 얇은 팔 형상, 서보 건 케이블을 팔에 내장. |
| C형 서보 건 | C형이 가장 흔하고 X형은 접근성이 좋다. 서보 건은 가압력을 프로그램으로 제어(2~7kN)하고 공압 건보다 사이클이 30~40% 빠르다. 용접 시간은 5~40 사이클(60Hz). 모델은 C형이라 위에서 내려올 수 없고, 로봇 쪽에서 수평으로 들어가 플랜지 아래에 아래 전극을 넣는다. |
| 용접 지그: 레스트 패드 3개, 위치결정 핀, 공압 클램프 3개 | 3-2-1 위치결정 원리, 공압 클램프(스윙, 토글, 핀 클램프)가 용접 지그의 표준 구성. 클램프는 용접하는 동안 닫혀 있다. |
| 안전 펜스, 안전문 인터록 | 로봇 용접 셀의 일반 구성 (컨베이어가 드나드는 틈은 비움). |

동작: 부품 가장자리 플랜지의 세 점을 차례로 용접합니다. 접근, 건 닫힘(가압), 불꽃, 건 열림, 후퇴를 반복하고, 관절 각도는 역기구학(`src/weld_cell.py`)으로 구합니다.

## 도장 (전착 도장)

| 모델 요소 | 근거 |
|---|---|
| 공정 순서 | 전처리(탈지, 수세, 인산아연 피막) -> 전착조 -> 후수세(UF, DI) -> 건조로. 전처리는 보통 8~11개 탱크. |
| 전착조, 양극, 정류기 | 도료는 탈이온수 80~90%와 도료 고형분 10~20%의 욕이고, 부품이 음극, 탱크가 양극인 직류 전착이다. 욕온은 약 28도(최소 15도 유지). 탱크는 에폭시 라이닝 강판. |
| 오버헤드 컨베이어의 행거가 부품을 담근다 | 부품을 오버헤드 컨베이어에서 탱크로 내리고 전압을 건다. 모델은 호이스트 로드가 부품을 내렸다 올린다. 전압을 거는 동안 정류기 램프가 켜진다. |
| 건조로 | 경화 구역 150~200도(보통 177도 20분). 증발 구역 80~120도. 부품이 보이도록 반투명 처리. |

## 모델의 알려진 한계
- 도장은 부품 한 개를 행거에 매달아 담그는 방식으로 단순화했습니다. 실제 라인은 연속 컨베이어와 여러 행거입니다.
- 전처리조와 후수세는 장식이며, 부품이 지나가지는 않습니다.
- 용접은 한 사이클에 세 점이며, 실제 부품의 점 수와 순서와는 다릅니다.
- 프레스 금형은 평평한 상, 하부 금형이고, 성형 형상과 스크랩은 표현하지 않았습니다.

## 점검 (tests/test_press_scene.py)
어깨 관절 높이 = IK 가정 높이, 용접 한 사이클에서 C형 건의 아래 팔이 작업대와 지그를 지나지 않음(옛 작업대 폭이면 2001개 중 881개 표본에서 닿는 것을 확인), 프레스 부품 높이와 금형 접촉면, 행거 로드와 호이스트 튜브의 연결, 컨베이어 통로가 막히지 않음.
