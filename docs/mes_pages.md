# MES 화면 구성 (추가한 5개 페이지)

MES(Auto Parts MES)의 왼쪽 메뉴에 라인별 페이지를 한 개씩 두고, 공장 전체를 보는 페이지를 맨 앞에 둡니다.
설치: `python src\mes_adapter.py --install-addons` (합쳐져서 없어진 옛 페이지는 설치할 때 MES 폴더에서 지웁니다).

| 번호 | 페이지 | 내용 | 3D |
|---|---|---|---|
| 13 | **공장현황** | 공장 전체 종합: 한눈에 보기, 주의가 필요한 일, 라인별 OEE, 생산, 품질, 계산 근거 | 전체 3D (3D 장면만 또는 조작 카드 포함) |
| 14 | **가공라인** | 가공 라인(PLC): 설비 효율(OEE), AI 이상 감지, 이벤트와 작업지시 (탭 3개) | **2D와 3D를 동시에** (좌우 또는 위아래), 결함 주입은 2D에서 |
| 15 | **프레스라인** | 프레스 · 용접 · 도장 라인: OEE, 공정별 시간 구성, 결함의 영향, 작업지시 · LOT · 검사 | 3D, 결함 주입, 배속 |
| 16 | **협동로봇셀** | 협동로봇 팔레타이징 셀: 비전 검사, 불량 검출, 적재, 파렛트, 집기 사이클. **조작 버튼**(라인 시작, 정지, 리셋, 배속, 파렛트 마감) | 이 구역을 확대한 3D |
| 17 | **물류출하** | 물류 · 출하 구역: 자재 재고, 입고 이력, 출하, 출하 대기, 검사 FAIL 로 막힌 LOT, 물류 이벤트. **조작 버튼**(라인 시작, 정지, 리셋, 배속, 입고 요청) | 이 구역을 확대한 3D |

## 정리한 것 (이전 구성)

| 옛 페이지 | 어디로 |
|---|---|
| 현장모니터링 (AI 이상 감지) | 가공라인 > "AI 이상 감지" 탭 |
| 설비현황 (OEE) | 가공라인 > "설비 효율 (OEE)" 탭 |
| 공정3D | 가공라인(2D / 3D 전환), 공장현황(전체 3D) |
| 프레스라인 | 프레스라인 (이름만 정리) |
| 공장현황 (재고, 출하 상세 포함) | 공장현황(종합)과 물류출하(재고, 출하 상세) |

MES 원본의 `13_현장모니터링.py`(아두이노 센서용)는 설치할 때 `13_현장모니터링.py.orig`로 백업한 뒤 지웁니다.
옛 이름의 페이지 파일(13_현장모니터링, 14_설비현황, 15_공정3D, 16_프레스라인, 17_공장현황)은 다시 설치해도 만들어지지 않습니다.

## 조작 버튼 (공장현황, 협동로봇셀, 물류출하)

세 페이지 위쪽에 **라인 조작** 막대가 있습니다. 3D 안의 카드를 켜지 않아도 MES 페이지의 버튼으로 트윈 서버의 조작 API를 부릅니다 (`mes/addons/src/twin_api.py`).

| 버튼 | 하는 일 |
|---|---|
| ▶ 라인 시작 / ■ 정지 / ↺ 리셋 | 프레스 · 용접 · 도장 라인. 협동로봇 셀과 물류 구역은 이 라인이 움직이면 따라서 움직입니다. 정지는 남은 부품을 내보낸 뒤 멈춥니다. |
| 배속 | x1, x2, x4, x8 (페이지를 열기만 해서는 바꾸지 않음) |
| 파렛트 마감 (협동로봇셀) | 모자란 파렛트도 지금 마감 |
| 입고 요청 (물류출하) | 재고와 상관없이 입고 트럭을 부름 |
| 가공 라인 연속동작 / 연속정지 (공장현황) | PLC 연속 동작 |

화면에는 라인 상태(가동, 정지 중, 투입, 양품, 불량, 배속)도 같이 나옵니다. 트윈 서버가 꺼져 있으면 경고와 오류 메시지가 나오고 페이지는 계속 동작합니다.
MES(Streamlit)가 서버 쪽에서 직접 호출하므로 **트윈 서버와 같은 컴퓨터**에서 열어야 하고, 다른 컴퓨터라면 "트윈 서버 주소"에 그 주소를 넣습니다.

## 3D 화면 연결

각 페이지의 3D는 트윈 서버의 화면을 `iframe`으로 끼웁니다 (트윈 서버 주소 입력칸, 기본 `http://localhost:5001`).
- 가공 라인: `/` (2D), `/3d` (3D)  ·  프레스 라인: `/3d/line`  ·  공장 전체: `/3d/factory`
- 협동로봇, 물류: `/3d/factory?embed=scene&focus=cobot` 또는 `focus=logistics` (그 구역을 확대한 시점. `embed=scene`은 3D 장면만, `embed=1`은 조작 카드 포함)
- 용어 전환(현장 용어 / 장비 원명칭)은 MES 사이드바의 **용어** 선택
