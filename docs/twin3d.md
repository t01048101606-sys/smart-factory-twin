# 3D 트윈

가공 공정 트윈을 three.js로 3D로 보여 줍니다. 2D 화면과 같은 `/api/state`를 쓰므로, PLC 상태(센서 X, 출력 Y, 작업물 위치)가 그대로 반영됩니다.

- 열기: 트윈 서버를 켜고 http://localhost:5001/3d  (2D 화면의 "3D로 보기" 링크, 3D 화면의 "2D로 보기" 링크로 오갑니다)
- MES: 설비현황, 현장모니터링 페이지의 **3D로 보기** 체크
- 조작: 마우스 왼쪽 드래그 = 회전, 휠 = 확대/축소, 오른쪽 드래그 = 이동. 아래쪽 버튼으로 동작, 정지, 결함 주입을 할 수 있습니다.
- 주소 옵션: `?embed=1`(제목 숨김), `?embed=view`(조작 패널도 숨김)

## 구성 (위에서 본 배치)

공급 실린더가 매거진의 작업물을 가공 위치로 밀고(X 방향) -> 드릴이 내려와 가공 -> 송출 실린더가 컨베이어 쪽으로 밀고(Z 방향)
-> 컨베이어 이동 -> 금속은 배출 실린더가 앞쪽 박스로 밀고, 비금속은 컨베이어 끝 박스까지 이동합니다. 신호등은 Y29/Y2A/Y2B를 따르고,
AI 이상 감지 경보가 있으면 빨간 불이 깜박이고 붉은 조명이 켜집니다.

| 보이는 것 | 반영하는 상태 |
|---|---|
| 공급, 송출, 배출 실린더 로드 | 솔레노이드 Y20/21, Y23/24, Y25/26 (꺼져 있으면 센서 X0~X7) |
| 드릴 비트 높이, 모터 색 | Y22(하강), Y28(드릴 모터) |
| 매거진의 작업물 | X8 (적재 센서) |
| 컨베이어 줄무늬 | Y27 |
| 작업물 위치와 색 | `pieces`(feed, drill, out, belt, eject, binm, end), 금속/비금속 |

## 오프라인에서 쓰려면

기본은 브라우저가 CDN(jsdelivr)에서 three.js를 불러오므로 인터넷이 필요합니다. 인터넷이 되는 곳에서 한 번만:

```
python tools\fetch_three.py
```

`src\static\vendor\`에 파일이 저장되고, 서버를 다시 켜면 `/3d`가 그 파일을 씁니다 (이 폴더는 Git에 올려 두면 다른 곳에서도 오프라인으로 열립니다).

## 시험과 한계

- `python tests\test_twin3d.py`: 가짜 three.js 위에서 실행해 오류, NaN, 작업물 위치 규칙을 확인합니다. **실제로 화면에 어떻게 보이는지는 브라우저에서 직접 확인해야 합니다.**
- 모델은 기본 도형(상자, 원기둥)입니다. 모델링 완성도보다 PLC와 실시간으로 같이 움직이는 것에 초점을 두었습니다.
- 다음 단계: 장면 정의를 JSON으로 분리해서 다른 공정(프레스, 용접, 도장 등)을 같은 뷰어로 보여 주기.
